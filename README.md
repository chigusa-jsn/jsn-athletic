# jsn-Athletic

マイクラ（NeoForge 1.21.1）で、アスレチックのコースを作るためのMOD。

## ブロック
- **仕掛けの台**：上に乗れる足場を出して、まわしたり（柱のまわりをアームと足場が回る）、往復させたり（左右・前後・上下）する。右クリックで設定（クリエイティブかOP）。レッドストーン（ボタン・レバー）で動かせる。
- **回るバー**：水平に回る棒。当たるとはじき飛ばされる。
- **落ちる床**：乗るとひびが入って、すぐに消える。3秒でもどる。
- **ジャンプ台**：乗ると高く飛ばされる（右クリックで強さ1〜5）。落ちてきてもダメージなし。
- **ベルトコンベア**：乗ると矢印の向きへ流される（右クリックで速さ、スニーク＋右クリックで向き）。
- **消えたり出たりする床**：赤→黄→緑→青の順に、1.5秒ずつ出たり消えたりする（消える前に点滅）。右クリックで色。
- **ふりこの鉄球**：台の下にぶら下がってゆれる鉄球。当たるとはじき飛ばされる。タイミングをずらして並べられる。
- **回転する角材**：長い角材が軸のまわりを回る。上に乗ると横に流されるので、逆に歩き続けよう。
- **スタート／チェックポイント／ゴール**：スタートの床から出るとタイム計測。ゴールに乗るとタイムが止まって、ランキングに残る。落ちるとチェックポイントにもどる（Rキーでも。長押しでやめる）。スタートを金床で名前をつけてから置くと、コースの名前になる。
